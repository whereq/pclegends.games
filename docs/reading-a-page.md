Every game in the archive has a page, and every page has the same shape.
This is what the parts mean.

## The header

The name, the year the bundle's own files are dated, and the size and file
count. Those four numbers are read out of the archive — the file list, the
file dates and the checksum of the file the page links to. The year in
particular is the year the *copy* was built, which is often a few years
after the game itself came out, and sometimes before.

## The notice

Every page carries a notice about the download. The archives are published
for study, communication and preservation only. They belong to their
authors and publishers, and publishing a link here claims none of those
rights and waives none of them. If you believe a download breaks a licence,
say so and it comes down.

## The infobox

The facts about the game: who made it, when it was published, what kind of
game it is, what it runs on, the file the bundle wants to be started from,
and what is in the bundle.

The **Developer** row often says *Not stated in the bundle*. That is not a
gap that was filled in later — it is the truth: a lot of shareware-era
DOS bundles carry no publisher information at all, and the page says so
rather than guessing.

## The body

The sections run in the same order on every page:

- **What it is** — the game, the size of the bundle, and where the facts
  came from.
- **Download the bundle** — the link, the size, the SHA-256, and the file
  list.
- **Set it up in WhereQ-DOSBox** — the entry point, and what to press.
- **How to play** — the keys and the screens, where they are known.
- **What is in the bundle** — the file list, broken down by what each file
  is for.
- **Where the facts come from** — the sources of everything on the page.

## "This setup has not been played through on the emulator yet"

Most pages say it. Only a handful of games have been run on an emulator
running WhereQ-DOSBox; those are on the [played-through shelf](/played),
and their pages say what worked rather than what is implied.

The line is not a disclaimer bolted on. It is the difference between a page
that reports what is in a bundle and a page that reports what happened
when somebody ran it. The archive can tell you the file list; only a person
at the keyboard can tell you which key starts the game.

## The comments

Every page carries a thread. If you got it running where the page could
not, that is what the thread is for — and the next reader will thank you
for writing down what you did.
